# Hermes Task Coach

A conversational task-accountability skill for Hermes Agent.

## Planned features

- Guided initial setup.
- Natural check-ins about individual tasks.
- Help identifying blockers and choosing practical next steps.
- Configurable timezone, notification windows, and follow-up frequency.
- A choice of supported messaging destinations.
- Local task storage, with optional task-provider integrations later.

## Status

Early development. This repository currently contains documentation only;
there is no installable skill or working runtime yet. The features listed
above are planned, not currently available.
